# Exercícios de Google Docs

Este repositório reúne exercícios e materiais desenvolvidos durante um período de ensino e acompanhamento de uma pessoa com o objetivo de desenvolver habilidades básicas no uso do **Google Docs**.

As atividades foram planejadas de forma gradual e prática, buscando facilitar o aprendizado e aumentar a familiaridade com recursos do editor de textos.

## Objetivos

- Desenvolver conhecimentos básicos em Google Docs;
- Praticar a criação e edição de documentos;
- Aprender a utilizar ferramentas de formatação;
- Trabalhar com textos, imagens e outros recursos;
- Incentivar maior autonomia no uso de ferramentas digitais.

## Conteúdo

Os exercícios disponíveis neste repositório foram utilizados como atividades práticas ao longo do processo de aprendizagem.

O foco principal foi proporcionar uma experiência simples, acessível e progressiva, especialmente considerando as necessidades de uma pessoa com mais idade.

## Sobre o projeto

Este repositório serve como um registro dos materiais e exercícios utilizados durante essa experiência de ensino, reunindo atividades que podem ser utilizadas novamente ou adaptadas para outros processos de aprendizagem.

---

**Tecnologia principal:** Google Docs  
**Finalidade:** Ensino e prática de ferramentas digitais
